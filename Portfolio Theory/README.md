# Portfolio Theory

Modern portfolio theory (MPT) is a theory on how risk-averse investors can construct portfolios to maximize expected return based on a given level of market risk.

### Diversification

There are two main types of risk:

1. **Unsystematic risk**: The risk that is inherent in a specific company or industry, we usually call that this type of risk is **diversifiable**.
2. **Systematic risk**: This refers to the risk inherent to the entire market or market segment, we usually call that this type of risk is **non-diversifiable**.

In terms of diversifying a portfolio according to the MPT, we would construct a portfolio to minimize the **Covariance & Correlation** between the assets in the portfolio. Therefore, it is highly important to understand how assets correlate between each other.

In a portfolio, with a given number of assets with estimated returns, variance and covariance, one would want to choose the **weightings** in each asset as to maximise the return, while minimising the variance.
